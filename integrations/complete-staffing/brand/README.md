# Complete Staffing — brand assets

Source logos supplied by Complete Staffing, plus web-ready derivatives.

| File | Use |
| --- | --- |
| `logo-full.webp` | Full lockup (figures + "COMPLETE STAFFING / MEDICAL PROFESSIONALS"), transparent background. The wordmark is white/silver, so place it on dark or photo backgrounds only. |
| `app-icon.webp` | Square app icon (dark rounded tile), source for the icon sizes below. |
| `mark-wide.png` | Figures-only mark, transparent, 120px tall. Used in site headers next to the text name; reads on light and dark. |
| `mark.png`, `mark-128.png` | Same mark centered on a square transparent canvas (512 / 128px), for avatars and social. |
| `favicon.ico`, `icon-32.png` | Browser tab icon. |
| `icon-180.png` | `apple-touch-icon`. |
| `icon-512.png` | PWA manifest / store-size icon. |

Logo colors (sampled): navy `#032B5B`, royal blue `#035FB2`, teal `#06DAC9`, deep teal `#009186`.
